# 🌸 えみラボ体操教室アプリ Ver.1

## 📌 プロジェクト概要

**えみラボ体操教室アプリ**は、先生の事務負担を減らし、生徒とのつながりを深めることを目的として開発した体操教室専用アプリです。

先生はGoogleカレンダーやGoogleスプレッドシートを利用して簡単に情報を更新でき、生徒はスマートフォンからいつでもレッスン動画やスケジュール、お知らせを確認できます。

## 2026/07 ボイスレッスン再生改善

### 変更内容
- Google Drive共有URLからファイルIDを自動抽出
- ブラウザ標準 `<audio controls>` による再生へ変更
- アプリ内再生に失敗した場合は「音声を開く」へ誘導
- スプレッドシート・GASの運用は変更なし

### 目的
- Google Driveプレビュー再生を避け、音質改善を図る
- 生徒の操作性向上
- 先生の運用方法は変更不要

- ## 2026/07 アイコン仕様をSophia標準へ統一

ホーム画面へ追加した際の表示品質向上のため、アイコン仕様をSophia標準へ変更。

### 変更内容
- iPhone用 `apple-touch-icon.png`（180×180）を追加
- Android用 `icon-192.png`（192×192）を追加
- Android用 `icon-512.png`（512×512）を追加
- `manifest.json` を標準構成へ更新
- `index.html` に以下を追加
  - `manifest`
  - `apple-touch-icon`
  - `favicon`
  - `theme-color`

### 目的
- iPhone・Android双方でホーム画面アイコンを最適表示
- PWA標準仕様へ対応
- 今後のSophia制作アプリと仕様を統一

### アプリへの影響
- ホーム画面アイコン表示のみ変更
- ログイン・動画・ボイス・スケジュール・お知らせ等の機能には影響なし
